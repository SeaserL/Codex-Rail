# Codex Rail 0.14.0

Initial public candidate for Windows 10/11 x64. / Windows 10/11 x64 首次公开候选。

- Sidebar-shaped overlay with mixed gauges, quota remaining and session metrics.
- English / Chinese / system language, themes, font/background imports and live preview.
- DPI-aware settings, work-area fitting, pagination and cached native fade surfaces.

Extract the portable ZIP; run the standalone EXE unless you already have the .NET 10 Desktop Runtime. The archive includes both variants, license notices and `SHA256SUMS.txt`. Both variants are unsigned. Quota availability and desktop IPC depend on your Codex version/account; missing values show `—`.

未安装 .NET 10 Desktop Runtime 时选择 standalone；校验 `SHA256SUMS.txt`。两个版本均未签名。字段可用性依赖 Codex 版本/账户，缺失值显示 `—`。

Read README for installation, supported platforms, privacy and test boundaries. This is an independent overlay, not an official OpenAI extension.
